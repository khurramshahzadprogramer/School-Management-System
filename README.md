A modern, full-featured, and lightning-fast **School Management ERP System** designed to digitize and streamline administrative tasks, student tracking, academic reports, and role-based portal access for educational institutions.

Inspired by reference identity: [esylearning.com](https://www.esylearning.com)

---

## ✨ Key Features & Portals

* 🔐 **Secure Role-Based Access Control (RBAC):** Dedicated, secure dashboards and granular permissions for Super Admin, School Admin, Accountants, Teachers, Parents, and Students.
* 🎓 **Student Information System (SIS):** Complete student enrollment lifecycle, detailed academic records, live attendance tracking, and comprehensive performance reports.
* 💳 **Fee Management & Invoicing:** Advanced fee structure management, automated payment invoice generation, tracking pending dues, and detailed transaction history logs.
* 📢 **Announcements & Notices:** Real-time school-wide or class-specific broadcasting system to keep students, teachers, and parents updated instantly.
* 📊 **Academic Reports & Analytics:** Automated generation of report cards, attendance summaries, and financial analytics for administrative oversight.
* 📱 **Responsive & Modern UI:** Crafted with a clean, mobile-first design philosophy optimized seamlessly for desktops, tablets, and smartphones.

## 🚀 Getting Started Locally

To set up and run this project locally on your machine, follow these simple steps:

### Prerequisites
Make sure you have **Node.js** and **npm** installed on your computer.
