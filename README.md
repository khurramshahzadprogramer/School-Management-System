# M.E Foundations School Management ERP

A professional, modern, full-featured School Management ERP built for **M.E Foundations School** (Inspired by reference identity: `www.esylearning.com`).

## Features
- **Secure Authentication & Roles:** Super Admin, School Admin, Accountant, Teacher, Parent, Student roles.
- **Student Management:** Full CRUD operations (Add, View, Delete, Search) with LocalStorage persistence.
- **Teacher & Faculty Directory:** Departmental breakdown and workload assignments.
- **Daily Attendance System:** Interactive status marking (Present, Absent, Late).
- **Fee Management:** Invoice tracking, dues, and payment statuses in PKR.
- **Notices & Communication:** Broadcast announcements and priority alerts.
- **Audit Logs & Reports:** Real-time administrative activity trail.
- **Cinematic Light Theme:** Clean enterprise SaaS styling with Tailwind CSS and Lucide React icons.

## Tech Stack
- React.js + Vite
- Tailwind CSS
- React Router DOM
- Lucide React Icons
- LocalStorage state persistence

## Installation & Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start development server:
   ```bash
   npm run dev
   ```

3. Open in your browser at `http://localhost:5173`.
